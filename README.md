# 🎬 FrameStudio - 동영상 프레임 자동 추출 프로그램

동영상 파일을 넣으면 원하는 간격, 개수, 또는 초당 프레임(FPS)에 맞춰 고화질 이미지를 자동으로 추출해주는 프로그램입니다.

사용자의 편의에 맞춰 **두 가지 방식**으로 제공됩니다:
1. **웹 인터페이스 (추천)**: 설치 없이 브라우저에서 바로 사용 가능한 프리미엄 대시보드 UI (실시간 갤러리 + 일괄 ZIP 다운로드)
2. **파이썬 자동화 스크립트**: 폴더 내 대량 파일이나 터미널 자동화를 위한 스크립트

---

## 🚀 빠른 시작 (Quick Start)

### 방법 1. 웹 스튜디오로 사용하기 (가장 간편 & 강력)
1. **`index.html`** 파일을 더블 클릭하여 크롬/엣지 브라우저에서 바로 열거나,
2. **`start_web.bat`** 파일을 더블 클릭하여 실행합니다.
3. 브라우저 창에서:
   - **방법 A (파일 업로드)**: 내 컴퓨터의 동영상 파일(MP4, WebM 등)을 드래그 앤 드롭합니다.
   - **방법 B (웹 링크)**: `[링크(URL) 가져오기]` 탭을 누른 뒤 **유튜브(일반/Shorts), 인스타 릴스, 틱톡, 웹 비디오 링크**를 붙여넣고 `[가져오기]`를 누르면 자동으로 영상을 불러옵니다!
   - 추출 모드(장면 전환 감지, 시간 간격, 총 개수, FPS)를 선택합니다.
   - **[프레임 자동 추출 시작]** 버튼을 클릭합니다.
   - 추출된 이미지를 실시간으로 확인하고, **[전체 ZIP 압축 다운로드]**를 클릭해 한 번에 저장합니다.

> 💡 동영상 파일이나 링크가 당장 없다면 화면의 **[샘플 데모 비디오로 시험해보기]**를 누르면 즉석에서 생성된 테스트 비디오로 바로 체험해볼 수 있습니다.

---

### 방법 2. 파이썬 스크립트로 사용하기 (OpenCV 기반)

#### 1) GUI 창으로 실행 (더블 클릭)
- **`run_python.bat`** 파일을 더블 클릭하면 OpenCV가 없을 시 자동 설치된 후 파일 선택 창이 열립니다.

#### 2) CLI 명령어 사용
```bash
# 필수 라이브러리 설치
pip install -r requirements.txt

# 1. 매 1초마다 프레임 추출 (기본값)
python extract_frames.py my_video.mp4 --interval 1.0

# 2. 영상 전체에서 균등하게 총 50장 추출
python extract_frames.py my_video.mp4 --count 50

# 3. 🎬 장면이 변할 때만 자동 감지하여 캡처 (스마트 컷 감지!)
python extract_frames.py my_video.mp4 --mode scene --scene-threshold 0.25

# 4. 초당 2장(2 FPS)씩 고화질 PNG 추출
python extract_frames.py my_video.mp4 --fps 2 --format png

# 5. 저장할 폴더 직접 지정
python extract_frames.py my_video.mp4 -o ./my_extracted_images
```

## 🌟 주요 기능

- **4가지 추출 모드**:
  - 🎬 **장면 전환 감지 모드 (스마트 컷)**: 영상의 배경이나 피사체 등 화면 구성이 변하는 **새로운 장면(Scene)의 시작 순간**만 자동으로 감지하여 캡처 (민감도 10%~60% 설정 가능)
  - **시간 간격 모드**: 매 X초마다 1장 캡처 (0.5초, 1초, 2초 등)
  - **균등 개수 모드**: 비디오 길이에 상관없이 정확히 N장 분할 캡처
  - **FPS 모드**: 초당 프레임 수 기반 캡처
- **구간 컷 (Range Crop)**: 특정 시작 초 ~ 종료 초 사이만 골라서 캡처
- **다양한 포맷 & 해상도**:
  - PNG (무손실 원본 품질), JPEG (압축 품질 0~100%), WebP 지원
  - 원본 해상도, 1080p, 720p, 50% 등 스케일 조절
- **원클릭 일괄 ZIP 압축 다운로드**: 추출된 모든 프레임을 브라우저 자체에서 즉시 ZIP 파일로 압축하여 다운로드
- **라이트박스 갤러리**: 추출된 프레임을 즉시 썸네일과 원본 크기로 확인하고 방향키(←, →)로 탐색 가능
- **완전한 로컬 처리**: 영상 파일이 외부 서버로 전송되지 않고 내 컴퓨터 내부에서 100% 안전하게 처리됩니다.
